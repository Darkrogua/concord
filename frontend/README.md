# Concord Frontend (Vue.js 3)

SPA приложение для системы согласования документов.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

- `src/components/` - компоненты
- `src/views/` - страницы
- `src/stores/` - Pinia stores
- `src/services/` - API сервисы
- `src/router/` - роутинг
