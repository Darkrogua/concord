# Компонент «Карточка согласования»

## Роль

Повторно используемый Vue-компонент для вывода краткой информации о согласовании в списках (дашборд, группы, поиск). Поддерживает режимы плотного отображения и карточки на всю ширину.

## Состав
- Заголовок и контекст (проект, автор, дата создания).
- Информационный бейдж статуса и прогресса по разделам.
- Метки дедлайна, важности и флаг «избранное».
- Быстрые действия: открыть детали, запустить, добавить в избранное, удалить в корзину.

## Зависимости
- Получает данные через Pinia store `useAgreementsStore`.
- Использует локальные утилиты форматирования дат, модуль уведомлений для всплывающих подтверждений.
- Встраивается в экраны «Дашборд» и «Группы согласований».
