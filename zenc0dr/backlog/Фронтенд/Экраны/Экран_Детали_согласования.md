# Экран «Детали согласования»

## Назначение

Показывает структуру конкретного согласования: информационные блоки, состав разделов, статусы голосований и историю активности. Здесь автор настраивает параметры и запускает процесс, а участники голосуют по своим разделам.

## Основные блоки
- **Хлебные крошки + название** для навигации назад и отображения статуса («Черновик», «Ждет согласования», «Завершено»).
- **Информационные блоки** по разделам: текст, файлы, ссылки, изображения, кодовые вставки.
- **Блок голосования**: переключатель Да/Нет, textarea для обязательного комментария при отказе, индикаторы видимости результатов.
- **История действий**: записи о запусках, напоминаниях, сбросах голосов, корректировках.

## Взаимодействие с другими слоями
- Для загрузки используется `GET /api/agreements/{id}` + вложенные запросы к разделам и блокам.
- Голосование отправляет `POST /api/sections/{sectionId}/vote` и обновляет состояние карточек участника на дашборде.
- Компоненты формы и истории переиспользуются на мобильных и гостевых представлениях.
