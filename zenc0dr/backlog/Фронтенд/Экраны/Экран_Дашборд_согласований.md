# Экран «Дашборд согласований»

## Назначение

Главная точка входа приложения: пользователь видит списки согласований (входящие, исходящие, избранные) и быстрые показатели статуса. Экран помогает оценить загрузку и перейти к нужному процессу.

## Основные блоки
- **Шапка** с поиском, переключением групп и быстрым фильтром по проектам (использует глобальные компоненты).
- **Секция списков**: табы «Входящие», «Исходящие», «Избранное», «Архив». Каждая вкладка выводит карточки согласований со статусом, дедлайном и индикаторами прогресса.
- **Боковая панель**: кнопки создания согласования, переходы в аналитику, напоминания и черновики.

## Взаимодействие с другими слоями
- Забирает данные через `GET /api/agreements` с параметрами фильтрации/сортировки.
- Показывает агрегации (количество непрочитанных, просроченных) из сервисов аналитики/уведомлений.
- Нажатие по карточке открывает экран деталей согласования.
