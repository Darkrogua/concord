# API слой «Участники разделов»

## Маршруты
- `GET /api/sections/{sectionId}/participants` — список прикрепленных пользователей.
- `POST /api/sections/{sectionId}/participants` — добавление единичного участника.
- `POST /api/sections/{sectionId}/participants/bulk` — вставка целой группы пользователей.
- `DELETE /api/sections/{sectionId}/participants/{userId}` — открепление участника.

## Бизнес-правила
- Открепление при активном согласовании инициирует сброс голоса и уведомление об изменении.
- Массовое добавление валидирует уникальность и роль пользователя, блокирует дубли.
- Группы пользователей выступают источником шаблонов для быстрого заполнения разделов.

## Технические детали
- Использует промежуточную таблицу `section_participants` с атрибутами роли, статуса, времени прикрепления.
- API отдаёт lightweight DTO, чтобы компоненты фронтенда могли отображать статус каждого участника.
- Связан с сервисом оркестрации и уведомлений (триггеры на изменение состава раздела).
