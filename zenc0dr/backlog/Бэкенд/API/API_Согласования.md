# API слой «Согласования»

## Маршруты
- `GET /api/agreements` — список с фильтрацией по группе, статусу, проекту, дедлайну.
- `POST /api/agreements` — создание нового согласования в статусе «Черновик».
- `PUT /api/agreements/{id}` — редактирование до запуска.
- `POST /api/agreements/{id}/publish` — запуск, инициирует сервис оркестрации.
- `POST /api/agreements/{id}/archive` / `POST /api/agreements/{id}/restore` — управление жизненным циклом.

## Контракты данных
- **AgreementSummary**: id, название, проект, статус, дедлайн, прогресс разделов, индикаторы избранного.
- **AgreementDetails**: включает разделы, участников, блоки, историю, доступные действия пользователя.

## Безопасность
- Все маршруты защищены Sanctum, дополнительные проверки ролей (автор, участник, наблюдатель).
- Тонкая авторизация: Policy проверяет кто может редактировать, запускать, архивировать.

## Связи с другими слоями
- Используется фронтенд-дашбордом, экраном деталей, сервисами аналитики и уведомлений.
- Поставляет события в очередь для realtime-обновлений (через Broadcasting).
