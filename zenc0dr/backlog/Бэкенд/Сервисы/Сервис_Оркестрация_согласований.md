# Сервис «Оркестрация согласований»

## Ответственность
Инкапсулирует бизнес-правила жизненного цикла согласования: создание, запуск, повторный запуск, архивирование, мягкое удаление, восстановление. Следит за дедлайнами и условиями завершения по всем разделам.

## Основные сценарии
1. **Создание**: валидирует структуру разделов, прикрепленных участников, создает информационные блоки и связывает файлы.
2. **Запуск**: проверяет готовность (все разделы заполнены, дедлайн установлен), переводит статус в «Ждет согласования», публикует задачи уведомлениям.
3. **Корректировка раздела**: сбрасывает голоса затронутых участников, создает события истории.
4. **Автозавершение**: по cron проверяет дедлайны и переводит документы в «Завершено» или «Просрочено» выполняя системные уведомления.

## API и инфраструктура
- Использует репозитории `Agreement`, `Section`, `Vote`.
- Работает через очереди Redis для долгих операций (массовые уведомления, копирование файлов).
- Отдает события в `AgreementEvent` (Laravel event/broadcast) для фронтенда.
