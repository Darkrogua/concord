# Сервис «Уведомления»

## Назначение
Обрабатывает события, связанные с изменениями в согласованиях, и доставляет их по нужным каналам (email, push, внутренние уведомления, напоминания). Работает асинхронно, чтобы не блокировать API.

## Потоки
- **События запуска**: информируют участников о новом согласовании или повторном запуске.
- **Напоминания**: периодически проверяет разделы с непроголосовавшими участниками и отправляет пинги за N часов/дней до дедлайна.
- **Системные сигналы**: уведомления авторам о просроченных документах, успехе/ошибке при импорте файлов.

## Технические детали
- Консьюмер очереди `notifications` в Redis, Laravel jobs.
- Использует шаблоны писем и REST вебхуки для внешних интеграций (на будущее).
- Сохраняет историю уведомлений в таблицу `notifications_log` для аналитики и отладки.
