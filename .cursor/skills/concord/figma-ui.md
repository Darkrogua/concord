# Concord — решения по UI (Figma)

Источник: [Прототип-ГОЛОСОВАЛКА](https://www.figma.com/design/feSKrIGntXofUOhbfuSQch/). Уточнения от заказчика — приоритет над догадками агента.

## Общий стиль

- Mobile-first, фиолетовый акцент, светлый фон
- Скругления ~12–16px на карточках и кнопках
- Бренд: **VC app** / **Согласие**

## Главная — «Все проекты»

Страница появляется при переходе на главную.

### Дефолтное содержимое

Последние **входящие** согласования, которые **мне нужно согласовать** (я согласователь, ещё не проголосовал).

### Шапка

| Элемент | Назначение |
|---------|------------|
| Заголовок «Все проекты» | Название страницы (не переключатель папок) |
| 🔍 | Поиск (оверлей) |
| **⋮ (три точки)** | **Быстрые настройки списка** (оверлей, см. ниже) |

### Меню ⋮ (быстрые настройки)

Оверлей поверх главной:

| Блок | Опции |
|------|--------|
| **Мои согласования** | Просроченные · С комментариями |
| **Другие согласования** | Просроченные · С комментариями |
| **Сортировка** | По активности · По сроку |
| Нижние действия | Прочитать все · Режим работы с задачами |

Отдельный полноэкранный поток **ФИЛЬТРАЦИЯ** (категории + теги-чипы) и **«Добавить свой фильтр»** — из кнопки «+ Добавить свой фильтр» в секциях фильтрации.

### Верхние табы (настраиваемые)

**По умолчанию:** **Согласования** · **Избранное** · **Архив**.

Пользователь может **сам настроить**, какие табы показывать. Дефолт — три перечисленных выше.

| Таб | Данные |
|-----|--------|
| **Согласования** | Основной список; дефолт — входящие на согласование |
| **Избранное** | `favorites` |
| **Архив** | `archived` |

### Сортировка / фильтрация списка

На макете: **«Фильтровать по»** → выпадающий список (напр. **«Сначала старые»**). Ранее встречалось «Сортировать по» / «Дате» — уточнять полный список опций при вёрстке.

### Карточка согласования (свёрнутая)

```
┌─────────────────────────────────────────┐
│ Договор № 1256 — …          10.05.2024 │
│ [бейдж статуса]              ⭐ 📋 ✏️   │
└─────────────────────────────────────────┘
```

| Элемент | Поведение |
|---------|-----------|
| Заголовок + дата | |
| **Бейдж статуса** | **Индикатор, не кнопка** (см. ниже) |
| ⭐ | Избранное |
| 📋 (копия) | **Дублирование** согласования |
| ✏️ | Редактирование — **только создатель** |

**Тап по свёрнутой карточке** → раскрытие **на месте** (аккордеон).

**Тап по раскрытой карточке** → переход на **экран согласования** (следующий экран в Figma):

| Роль | Поведение |
|------|-----------|
| **Согласователь** | Видит все разделы; **голосовать** может только по разделам, где он прикреплён (**активные**). Остальные разделы видны, но **неактивны** |
| **Автор** | (уточнить на скрине экрана согласования) |

Отдельной страницы «детали» из свёрнутого состояния нет — только аккордеон, затем провал в карточку согласования.

### Бейджи статуса (не кнопки!)

| Вид | Значение |
|-----|----------|
| Зелёная заливка «Согласовано» | Согласовано |
| Серая обводка «Ждет согласования» | В процессе |
| Красная обводка «Ждет согласования» | Просрочено (дедлайн) |

### Карточка раскрытая

- Раскрывается в списке, без навигации
- Под шапкой карточки — **разделы согласования** (на макете: «Дизайн», «Программирование», «Маркетинг»)
- Каждый раздел:
  - Название раздела
  - Счётчик с галочкой: **«N из M»** (проголосовали «Да» / всего участников раздела)
  - **Горизонтальный progress bar**: светло-фиолетовый трек, фиолетовая заливка, вертикальная метка на позиции прогресса
- Состояния бара (справа на макете): пустой (0%), частичный, полный (100%)
- Бейдж статуса на карточке — **индикатор всего согласования**, не раздела
- Тап по разделу → экран голосования / чтения раздела (отдельный UX, уточнить на следующих скринах)

### Поиск

Оверлей: стрелка назад, поле «Поиск», крестик очистки. Фиолетовая шапка поиска.

## Создание — «Новый проект» (+)

Bottom sheet при тапе на **Новый проект** в нижней nav:

| Элемент | Содержание |
|---------|------------|
| Заголовок | **Создать** |
| Пункты | **Голосование** · **Согласование** (radio, одна выбрана) |
| Иконка слева | Круг с буквой активной подписи |
| Кнопки | **Отмена** (лавандовая) · **Сохранить** (фиолетовая) |

- Ручка сверху, разделители между пунктами
- **Сохранить** — переход к созданию выбранного типа

## Мульти-подпись

Bottom sheet «Сменить аккаунт» из профиля (нижняя nav):

- Ручка сверху, лавандовый фон
- Список аккаунтов: **аватар · имя · radio** справа
- Разделители между пунктами
- Внизу: **+ СОЗДАТЬ НОВЫЙ АККАУНТ** (без radio)
- Переключение подписей / контекстов
- Все действия и данные — от имени **активной подписи**
