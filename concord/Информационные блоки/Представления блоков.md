# Представления блоков

Описание визуального представления различных блоков в интерфейсе приложения.

## Текстовый блок

### Особенности:
- Если заголовок не указан создателем, он не отображается для конечного пользователя
- Заголовок можно редактировать создателю блока
- Поддерживает форматирование: выделение текста, заголовки разных уровней, списки (нумерованные и маркированные), ссылки, эмодзи

## Блок с картинками (Галерея)

### Особенности:
- Группа картинок, отображаемых вместе
- Можно просматривать изображения в галерее
- Подписи к изображениям опциональны

## Блок с файлами

### Особенности:
- Ограничение: не более 50 МБ на файл
- Можно скачивать файлы
- Поддерживаемые форматы: xlsx, doc, json, pdf и другие офисные документы
- Отображается иконка типа файла рядом с названием

## Блок со ссылками

### Особенности:
- Ссылки форматированы для удобного просмотра
- Могут иметь превью страницы
- Кликабельные элементы

## Блок с кодом

### Особенности:
- Отображение кода без форматирования
- Сохранение исходного форматирования кода
- Подсветка синтаксиса (если поддерживается)
- Кнопка копирования кода

## Блок согласования

### Особенности:
- Всегда находится в конце раздела
- Отображает вопрос "Согласовать?" с кнопками "Да" и "Нет"
- При голосовании "Нет" обязателен комментарий (поле "Почему?")
- Индикатор пламени меняет цвет в зависимости от близости дедлайна (чем ближе, тем ярче/краснее)
- Результаты отображаются в том же блоке после голосования
- Показывает информацию о дедлайне и участниках

## Раздел согласования

### Особенности:
- Разделы отображаются лентой сверху вниз (вертикальная прокрутка)
- Можно сворачивать/разворачивать разделы
- Каждый раздел визуально отделен от других
- Содержит информационные блоки и блок согласования в конце

## Карточка согласования (в списке)

### Особенности:
- Отображает ID, название, дату создания, автора
- Показывает статус согласования
- Иконка пламени меняет цвет в зависимости от близости дедлайна
- Прогресс: "X/Y" (количество согласованных разделов из общего числа)
- Прогресс-бар показывает процент согласованных разделов
- Иконки действий: избранное, копирование, редактирование

## Нижняя навигационная панель

### Особенности:
- Всегда видна на всех экранах
- Пять вкладок: Согласования, Настройки, Создать, Уведомления, Профиль
- Центральная кнопка "Создать" может быть больше остальных
- Уведомления могут иметь бейдж с количеством непрочитанных
- Активная вкладка выделена фиолетовым цветом
