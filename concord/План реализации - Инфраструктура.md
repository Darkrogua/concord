# План реализации - Инфраструктура

## Настройка окружения разработки

### 1. Laravel проект

```bash
# Создание нового Laravel проекта
composer create-project laravel/laravel concord-backend

# Переход в директорию
cd concord-backend

# Установка зависимостей для API
composer require laravel/sanctum
composer require spatie/laravel-permission  # для ролей (если нужно)
```

### 2. Vue.js проект

```bash
# Создание нового Vue.js проекта
npm create vue@latest concord-frontend

# Или через Vite
npm create vite@latest concord-frontend -- --template vue

# Установка зависимостей
cd concord-frontend
npm install
npm install axios vue-router pinia
```

### 3. PostgreSQL

- Создать базу данных `concord`
- Настроить подключение в `.env` Laravel
- Проверить подключение

### 4. Redis

- Установить и запустить Redis
- Настроить в `.env` Laravel
- Использовать для очередей и кэша

### 5. Конфигурация Laravel

- Настроить `.env` файл
- Настроить `config/database.php` для PostgreSQL
- Настроить `config/queue.php` для Redis
- Настроить `config/cache.php` для Redis
- Настроить `config/filesystems.php` для локального хранилища

### 6. Конфигурация Vue.js

- Настроить `.env` для API endpoint
- Настроить axios interceptor
- Настроить роутинг
- Настроить state management (Pinia)

## Структура проекта

```
concord/
├── backend/          # Laravel API
│   ├── app/
│   ├── database/
│   ├── routes/
│   └── ...
├── frontend/         # Vue.js SPA
│   ├── src/
│   ├── public/
│   └── ...
└── docs/             # Документация (текущая папка)
```

## Команды для разработки

### Backend
```bash
php artisan serve
php artisan queue:work
php artisan schedule:work  # для cron задач
```

### Frontend
```bash
npm run dev
npm run build
```
