Роль:
  - Автор
---
Данный пользователь имеет возможность создавать согласования.

## Возможности автора:

- Создает согласования с разделами и информационными блоками
- Может редактировать согласование только до запуска
- Может корректировать разделы при активном согласовании (после запуска)
- При корректировке раздела все голоса по этому разделу сбрасываются
- Участники, чьи голоса сброшены, получают уведомление о необходимости проголосовать повторно
- Видит результаты голосования в реальном времени
- Видит комментарии к отказам (видны только автору)
- Может удалять согласования (мягкое удаление в корзину)
- Может архивировать согласования вручную
- Может повторно запустить согласование после завершения (с редактированием или без)
- Может видеть статистику по разделам (сколько согласовано, сколько осталось)
