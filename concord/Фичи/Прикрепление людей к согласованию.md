Прикрепление участников (согласователей) к конкретным разделам согласования.

## Особенности:

- Участники прикрепляются к конкретным разделам, не ко всему согласованию
- Один участник может быть прикреплен к нескольким разделам одного согласования
- Прикрепление происходит через экран "Добавление подписантов"

## Способы добавления участников:

1. **Добавление по одному:**
   - Поиск по всем пользователям в проекте
   - Выбор пользователя из списка
   - Отметка чекбоксом

2. **Выбор группы пользователей:**
   - Открывается список групп пользователей
   - Можно выбрать одну или несколько групп
   - Пользователи из выбранных групп автоматически выбираются в списке

3. **Создание новой группы пользователей:**
   - Открывается экран для ввода названия группы
   - Выбор пользователей галочками
   - Созданная группа сохраняется для дальнейшего использования

4. **Отметить всех:**
   - Выбирает всех пользователей в проекте, кроме самого автора

## Поиск участников:

- Поиск работает по всем пользователям в проекте
- Даже если автор с ними не взаимодействовал ранее
- Поиск по имени, email или другим параметрам
