Возможность прочесть все [[Раздел - Контейнер|разделы]] [[Согласование|согласования]] с учетом уровня доступа к различным разделам. **Сюда не включен функционал [[Подпись|подписания]]

## Особенности отображения:

- Разделы отображаются лентой сверху вниз (вертикальная прокрутка)
- Разделы можно сворачивать/разворачивать
- Все пользователи видят все информационные блоки разделов
- Если пользователь является участником голосования в разделе, он видит блок согласования с кнопками "Да" и "Нет"
- Если пользователь не является участником раздела, он видит только информационные блоки без блока согласования

## Для гостя:

- Может только читать информационные блоки разделов
- Не видит результаты голосования
- Не видит блок согласования
- Доступ только по публичной ссылке на согласование

## Для согласователя:

- Видит информационные блоки разделов
- Видит блок согласования в разделах, к которым прикреплен
- После голосования видит результаты в том же блоке согласования
- Видит результаты других участников (если включена видимость в настройках раздела)

## Для автора:

- Видит все разделы и информационные блоки
- Видит результаты голосования в реальном времени
- Видит комментарии к отказам
- Может видеть статистику по разделам (сколько согласовано, сколько осталось)
