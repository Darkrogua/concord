# Инструкции по установке и настройке

## Шаг 1: Установка зависимостей системы

### Требования
- PHP 8.2 или выше
- Composer
- Node.js 18+ и npm
- PostgreSQL 15+
- Redis 7+

### Установка через Docker (рекомендуется)

```bash
# Запустить PostgreSQL и Redis
docker-compose up -d

# Проверить статус
docker-compose ps
```

## Шаг 2: Создание Laravel проекта

```bash
cd /home/darkrogua/work/concord/backend

# Создать новый Laravel проект (если еще не создан)
composer create-project laravel/laravel . --prefer-dist

# Или если проект уже существует, установить зависимости
composer install
```

### Настройка .env

Создать файл `.env` на основе `.env.example`:

```env
APP_NAME=Concord
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=concord
DB_USERNAME=postgres
DB_PASSWORD=postgres

QUEUE_CONNECTION=redis
CACHE_DRIVER=redis
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

MAIL_MAILER=smtp
MAIL_HOST=mailpit
MAIL_PORT=1025
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=null
MAIL_FROM_ADDRESS="hello@example.com"
MAIL_FROM_NAME="${APP_NAME}"
```

### Генерация ключа приложения

```bash
php artisan key:generate
```

### Установка Laravel Sanctum

```bash
composer require laravel/sanctum
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"
php artisan migrate
```

## Шаг 3: Создание Vue.js проекта

```bash
cd /home/darkrogua/work/concord/frontend

# Создать новый Vue.js проект
npm create vue@latest . -- --typescript false

# Или если проект уже существует, установить зависимости
npm install

# Установить дополнительные зависимости
npm install axios vue-router@4 pinia
```

### Настройка .env

Создать файл `.env`:

```env
VITE_API_URL=http://localhost:8000/api
```

## Шаг 4: Настройка CORS в Laravel

В файле `config/cors.php` убедиться, что разрешены запросы с фронтенда:

```php
'paths' => ['api/*', 'sanctum/csrf-cookie'],
'allowed_origins' => ['http://localhost:5173'], // Vite dev server
'allowed_methods' => ['*'],
'allowed_headers' => ['*'],
'supports_credentials' => true,
```

## Шаг 5: Проверка подключения к базе данных

```bash
cd backend
php artisan migrate:status
```

Если база данных пустая, можно создать тестовую миграцию для проверки:

```bash
php artisan make:migration test_connection
# В миграции ничего не делать, просто проверить подключение
php artisan migrate
```

## Шаг 6: Запуск проектов

### Backend (в отдельном терминале)

```bash
cd backend
php artisan serve
```

### Backend Queue Worker (в отдельном терминале)

```bash
cd backend
php artisan queue:work redis
```

### Frontend (в отдельном терминале)

```bash
cd frontend
npm run dev
```

## Шаг 7: Проверка работы

1. Backend должен быть доступен по адресу: http://localhost:8000
2. Frontend должен быть доступен по адресу: http://localhost:5173
3. API должен быть доступен по адресу: http://localhost:8000/api
