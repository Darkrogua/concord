# План реализации системы согласования

## Общая структура плана

План разбит на несколько файлов:
- `План реализации - Общий.md` - этот файл, общая структура
- `План реализации - Backend.md` - детальный план бэкенда (Laravel)
- `План реализации - Frontend.md` - детальный план фронтенда (Vue.js)
- `План реализации - База данных.md` - схема базы данных и миграции
- `План реализации - Инфраструктура.md` - настройка окружения, очереди, кэш

## Технологический стек

- **Backend**: Laravel 11
- **Frontend**: Vue.js 3 (SPA)
- **База данных**: PostgreSQL
- **Очереди**: Redis
- **Кэш**: Redis
- **Файлы**: Локальное хранилище (v1)

## Этапы разработки

### Этап 1: Настройка проекта и инфраструктура
- Настройка Laravel проекта
- Настройка Vue.js проекта
- Настройка PostgreSQL
- Настройка Redis
- Настройка окружения разработки

### Этап 2: База данных и модели
- Создание схемы базы данных
- Миграции
- Модели Eloquent
- Связи между моделями

### Этап 3: Backend API (v1 фичи)
- Аутентификация и авторизация
- CRUD для согласований
- CRUD для разделов
- Голосование
- Уведомления
- Файлы

### Этап 4: Frontend (v1 фичи)
- Настройка Vue.js проекта
- Компоненты интерфейса
- Страницы и роутинг
- Интеграция с API

### Этап 5: Фоновые задачи
- Очереди для уведомлений
- Автоматический запуск отложенных согласований
- Автоматическая архивация

## Приоритеты

Все фичи с пометкой v1 из списка "!Все фичи.md" должны быть реализованы в первую очередь.

См. детальные планы в соответствующих файлах.
