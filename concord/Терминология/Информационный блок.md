Представляют собой блоки с информацией различного вида, наиболее часто встречающие типы:

1. **Текстовый блок** - выделение текста, смена размера заголовка, списки нумерованные и нет, ссылки, обычный текст.

2. **Блок со ссылками** - форматированный вывод ссылок

3. **Блок с файлами** - разрешенные форматы обычные документы xlsx, doc, json, pdf и т.д. Ограничения: не более 50 МБ. Можно скачивать файлы.

4. **Блок с картинками (Галерея)** - группа картинок, отображаемых вместе

5. **Блок с кодом** - отображение кода без форматирования

## Создание разделов:

- При нажатии плюса появляется выбор типов блоков (Файлы, Галерея, Текст-блок, Ссылка, Код)
- Выбор типа блока создает раздел
- После каждого блока есть плюс для добавления нового раздела или дублирования предыдущего
- Если информационный блок создан вне раздела, он автоматически создает раздел под себя
