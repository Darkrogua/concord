Каждое [[Согласование|согласование]] имеет свои параметры, например:
- автор
- дата создания
- дата завершения
- важность (v2)
- название
- описание
- дедлайн
- дата публикации (для отложенного запуска)
- проект/категория
- статус
- количество разделов
- количество согласованных разделов
- итд

Каждый этот параметр (и не только) является критерием, по которому в дальнейшем можно будет фильтровать согласования.

## Параметры для фильтрации в v1:

- Создана (дата создания)
- Участник
- Статус
- Проект

## Параметры для фильтрации в v2:

- Срочность/Важность
