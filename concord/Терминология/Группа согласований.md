 Список согласований собранных по определенным критериям согласования. Возможные критерии: 
1. Автор
2. Важность
3. Входящие
4. Срочность
5. Избранное
6. Архив

По умолчанию зарегистрированные пользователи будут иметь несколько созданных групп согласований:
1. Входящие
2. Исходящие (созданные пользователем)
3. Запущенные (подумать над фразой)
4. Все (все согласования кроме корзины)
5. Избранное 
6. Корзина (мягко удаленные согласования)
7. Завершенные
