# План реализации - База данных

## Схема базы данных

### Основные таблицы

#### users
- id (bigint, primary key)
- name (string)
- email (string, unique)
- email_verified_at (timestamp, nullable)
- password (string)
- remember_token (string, nullable)
- created_at, updated_at

#### signatures (мульти-подпись)
- id (bigint, primary key)
- user_id (bigint, foreign key -> users.id)
- name (string) - название подписи (рабочая, личная и т.д.)
- is_active (boolean) - активная подпись
- created_at, updated_at

#### projects (проекты/категории)
- id (bigint, primary key)
- name (string)
- user_id (bigint, foreign key -> users.id) - создатель проекта
- created_at, updated_at

#### agreements (согласования)
- id (bigint, primary key)
- title (string) - название
- description (text, nullable) - описание
- author_id (bigint, foreign key -> users.id)
- signature_id (bigint, foreign key -> signatures.id) - от какой подписи создано
- project_id (bigint, nullable, foreign key -> projects.id)
- deadline (timestamp) - дедлайн
- publish_date (timestamp, nullable) - дата публикации (для отложенного запуска)
- status (enum: draft, awaiting, completed, expired, archived, deleted)
- is_approved (boolean, nullable) - согласовано/не согласовано
- completed_at (timestamp, nullable)
- deleted_at (timestamp, nullable) - мягкое удаление
- created_at, updated_at

#### sections (разделы)
- id (bigint, primary key)
- agreement_id (bigint, foreign key -> agreements.id)
- name (string) - наименование
- order (integer) - порядок отображения
- completion_condition (enum: all, majority) - условия завершения (пока только all)
- show_results_before_vote (boolean) - показывать результаты до голосования
- participants_see_each_other (boolean) - участники видят друг друга
- is_approved (boolean, nullable) - согласован/не согласован
- approved_at (timestamp, nullable)
- created_at, updated_at

#### section_participants (участники разделов)
- id (bigint, primary key)
- section_id (bigint, foreign key -> sections.id)
- user_id (bigint, foreign key -> users.id)
- signature_id (bigint, foreign key -> signatures.id)
- created_at, updated_at
- unique(section_id, user_id, signature_id)

#### votes (голоса)
- id (bigint, primary key)
- section_id (bigint, foreign key -> sections.id)
- user_id (bigint, foreign key -> users.id)
- signature_id (bigint, foreign key -> signatures.id)
- vote (enum: yes, no)
- comment (text, nullable) - комментарий к отказу
- created_at, updated_at
- unique(section_id, user_id, signature_id)

#### information_blocks (информационные блоки)
- id (bigint, primary key)
- section_id (bigint, foreign key -> sections.id)
- type (enum: text, gallery, files, links, code)
- title (string, nullable)
- content (json) - содержимое блока
- order (integer) - порядок отображения
- created_at, updated_at

#### files (файлы)
- id (bigint, primary key)
- information_block_id (bigint, foreign key -> information_blocks.id)
- name (string)
- path (string) - путь к файлу
- size (bigint) - размер в байтах
- mime_type (string)
- created_at, updated_at

#### user_groups (группы пользователей)
- id (bigint, primary key)
- name (string)
- user_id (bigint, foreign key -> users.id) - создатель группы
- created_at, updated_at

#### user_group_members (участники групп)
- id (bigint, primary key)
- user_group_id (bigint, foreign key -> user_groups.id)
- user_id (bigint, foreign key -> users.id)
- created_at, updated_at
- unique(user_group_id, user_id)

#### agreement_groups (группы согласований)
- id (bigint, primary key)
- name (string)
- user_id (bigint, foreign key -> users.id) - создатель группы
- filters (json) - сохраненные фильтры
- is_default (boolean) - системная группа (Входящие, Исходящие и т.д.)
- created_at, updated_at

#### favorites (избранное)
- id (bigint, primary key)
- user_id (bigint, foreign key -> users.id)
- agreement_id (bigint, foreign key -> agreements.id)
- created_at, updated_at
- unique(user_id, agreement_id)

#### notifications (уведомления)
- id (bigint, primary key)
- user_id (bigint, foreign key -> users.id)
- type (string) - тип уведомления
- title (string)
- message (text)
- data (json, nullable) - дополнительные данные
- read_at (timestamp, nullable)
- created_at, updated_at

#### activity_logs (логи действий)
- id (bigint, primary key)
- user_id (bigint, nullable, foreign key -> users.id)
- signature_id (bigint, nullable, foreign key -> signatures.id)
- action (string) - действие
- model_type (string) - тип модели
- model_id (bigint) - ID модели
- changes (json, nullable) - изменения
- ip_address (string, nullable)
- user_agent (text, nullable)
- created_at

## Индексы

- agreements: author_id, status, deadline, publish_date, project_id
- sections: agreement_id, order
- votes: section_id, user_id, signature_id
- section_participants: section_id, user_id
- notifications: user_id, read_at
- activity_logs: user_id, model_type, model_id, created_at
