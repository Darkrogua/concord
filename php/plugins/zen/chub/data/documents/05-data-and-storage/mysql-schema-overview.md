# Основная схема базы данных плагина

Таблицы Zen.Chub в основной базе условно группируются для понимания зависимостей между модулями.

| Группа | Назначение |
|--------|------------|
| Ядро платформы плагина | Реестр типов сущностей, потоки, базы SQLite метаданных, расписание cron, команды, состояния как сущности БД при необходимости |
| Каталог круизного продукта | Теплоходы, палубы, классы судов, категории кают, провайдеры рейсов, включения и дополнительные услуги, технические спецификации и связанные справочники |
| Связующие таблицы | Связь многих ко многим между кораблями и услугами, палубами и категориями кают и аналогичные конструкции |
| Алиасы | Сопоставление внешних и внутренних кодов имён для интеграций и импортов |

Внешние ключи в MySQL могут быть не объявлены явно во всех таблицах; связи задаются на уровне моделей October. При изменении миграций проверяйте каскады удаления и уникальность составных ключей там, где запрещены дубликаты строк прайсов или связей палубы и категории.
