# Ядро плагина Zen.Chub

Zen.Chub — основной прикладной модуль проекта. В нём сосредоточены каталог круизных сущностей (теплоходы, палубы, категории кают, провайдеры и связанные справочники), системные механизмы (потоки, процессы, планировщик, команды, состояния, SQLite-базы для служебных данных), динамический HTTP API и реестр настраиваемых сущностей с генерацией CRUD.

Точка сборки плагина на стороне приложения — класс регистрации плагина: там подключаются расписание cron, настройки, виджеты отчётов, консольные команды и прочие расширения жизненного цикла. Навигация в админке строится вокруг единого корневого раздела; фактическая структура подменю может опираться на файл реестра сущностей, чтобы экраны для новых типов записей появлялись без ручного дублирования конфигурации.

Рекомендуется не раздувать класс регистрации «всём подряд»: новые возможности оформляются отдельными контроллерами, моделями и сервисными классами, а в регистраторе остаётся только связывание.
