# Реестр сущностей и генерация CRUD

**Менеджер сущностей** хранит метаданные о типах записей, которые должны получить стандартные экраны списка и формы в админке. На основе этого реестра строится навигация и поведение CRUD без копирования однотипных конфигураций для каждой модели вручную.

Для операций с реестром и генерации связанных артефактов предусмотрена консольная команда **chub:entity**. Её следует использовать как основной вход при добавлении или изменении записей реестра сущностей: так сохраняется согласованность между JSON-конфигурацией, кодом и правилами команды.

Практическая польза для нового разработчика: перед созданием «ещё одного» административного раздела с нуля стоит проверить, не покрывается ли задача расширением реестра сущностей и генерацией, что снижает объём шаблонного кода и единообразно подключает модель к общим механизмам плагина.
