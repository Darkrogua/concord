# Подсистемы выполнения процессов

Под **runtime** в контексте Zen.Chub понимают компоненты, которые управляют длительными и фоновыми задачами: **потоки** (Stream), **процессы** и **менеджер Flow**, **планировщик cron**, **консольные команды**, **состояния** (States) и **отдельные SQLite-файлы** для служебных данных и журналов, не смешиваемые с основной реляционной базой приложения.

Эти части связаны общей идеей: бизнес-данные в MySQL (или основной БД проекта), а операционная телеметрия, очереди рассмотрения, логи выполнения команд и прочие «рабочие» массивы — в предсказуемых местах файловой системы согласно настройкам плагина.

При отладке фоновых задач опирайтесь на журналы и структуру SQLite-баз, описанную в профильных заметках этого раздела, и на то, как команды и cron регистрируются в плагине.
