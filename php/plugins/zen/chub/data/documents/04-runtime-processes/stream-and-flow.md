# Потоки Stream и процессы Flow

**Stream** отвечает за обработку потоковых сценариев: поступление данных, этапы обработки и связь с остальной системой без необходимости держать всё в одном синхронном запросе HTTP.

**Flow** и связанный с ним менеджер процессов описывают более «сквозные» сценарии выполнения работы (цепочки шагов, состояние процесса, взаимодействие с командами и расписанием).

Оба механизма реализованы сервисными классами в кодовой базе плагина; при добавлении нового сценария предпочтительно искать существующие паттерны в аналогичных процессах, а не дублировать логику в контроллерах админки. Контроллеры предназначены для UI и точечных действий пользователя, а не для тяжёлой оркестрации.
