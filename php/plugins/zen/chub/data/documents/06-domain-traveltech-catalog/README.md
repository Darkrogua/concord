# Предметная область: каталог TravelTech

Бизнес-контент Zen.Chub в части туристического продукта завязан на каталог водного транспорта и размещения: **теплоход**, **палубы**, **категории кают**, **провайдеры**, а также справочники включений, доплат, удобств и технических характеристик. Связи между сущностями отражают то, как на практике собирается предложение: какой корабль, какие палубы доступны, какие категории кают на каких палубах представлены, какие услуги входят в базовую стоимость или оплачиваются отдельно.

**Алиасы** позволяют сопоставлять обозначения из внешних систем и прайсов с внутренними записями без жёсткой привязки к одному текстовому названию.

При разработке новых экранов и API опирайтесь на уже принятую терминологию в моделях и админке: «теплоход», «палуба», «категория кают», «провайдер», чтобы команда и контент-менеджеры говорили на одном языке с кодом.
