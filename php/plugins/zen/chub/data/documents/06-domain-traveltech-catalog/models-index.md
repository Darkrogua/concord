# Основные модели каталога

Ниже перечислены ключевые сущности предметной области и их роль. Имена моделей в коде соответствуют англоязычным классам October; пользовательские подписи в интерфейсе могут быть на русском.

| Сущность | Роль в каталоге |
|----------|-----------------|
| Теплоход | Единица продукта «корабль»: базовые поля, активность, сортировка, связь с классом судна при необходимости |
| Класс теплохода | Группировка судов по классу для фильтрации и отображения |
| Палуба | Уровень размещения на конкретном теплоходе; может участвовать в иерархии для отображения имён на фронте |
| Категория кают | Тип размещения по комфортности и составу; связь с теплоходом и палубами задаётся через модель данных и связи |
| Провайдер | Источник рейса или турпакета во внешней логике интеграций |
| Включение в стоимость | Опция, входящая в базовую цену для выбранного теплохода |
| Доплата | Услуга или сбор с отдельной тарификацией |
| Удобство на борту | Признак инфраструктуры судна для маркетингового блока |
| Техническая характеристика | Структурированное описание параметров судна |
| Оборудование каюты | Детали комплектации номера |

Дополнительно используются модели **алиасов** для сопоставления названий из внешних каталогов с внутренними идентификаторами. При импорте прайсов и расписаний без алиасов потребуется ручное сопоставление или расширение правил загрузки.
