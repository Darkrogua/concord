# Фронтенд: сборка Vite и тема

Пользовательская часть сайта опирается на тему проекта и сборку фронтенд-ресурсов через **Vite**. JavaScript и стили темы живут отдельно от PHP-плагина; инструменты сборки описаны в конфигурации репозитория.

Для плагина Zen.Chub также настроена **сборка административных и служебных скриптов** (например, расширенный редактор документов и связанные стили). Скомпилированные файлы попадают в каталог артефактов сборки плагина; их не следует править вручную после генерации.

Изоморфные или островные Vue-компоненты на витрине темы используются там, где нужна интерактивность без полной перезагрузки страницы. При изменении API бэкенда синхронизируйте контракт с фронтом и обновите типы или документацию для фронтенд-разработчиков в вашем процессе.
