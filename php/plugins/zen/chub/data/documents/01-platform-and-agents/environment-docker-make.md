# Среда: Docker и команды Make

Локальный стек собирается через Docker. Команды **Make** служат короткими именами для частых действий: запуск и остановка контейнеров, вывод статуса, просмотр журналов, проверка «здоровья» зависимостей. Конкретные имена целей могут меняться по мере развития Makefile; при появлении новой цели её назначение фиксируют в операционной документации команды.

Перед работой с базой данных и очередями убедитесь, что контейнеры подняты и приложение отвечает так, как ожидается в вашем окружении.

Пакет **Composer** и скрипты из **npm** используются там, где настроены соответствующие каталоги (например, сборка фронтенд-ассетов плагина через Vite). Для команд PHP из корня репозитория используется единый вход Artisan; это снижает ошибки из-за разных текущих каталогов при запуске.

Для проверки работоспособности после изменений конфигурации или обновления зависимостей имеет смысл пройти короткий чеклист: контейнеры, миграции при необходимости, доступность админки и smoke-проверки, если они приняты в вашем процессе.
