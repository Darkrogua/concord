# Платформа и участники разработки

Раздел описывает, как устроена рабочая среда проекта и как разработчик или автоматизированный агент получает доступ к инструментам без изучения разрозненных заметок.

Проект рассчитан на локальную разработку с использованием контейнеризации и типового набора команд **Make**: подъём окружения, проверка состояния сервисов, просмотр журналов. Artisan-команды October и Chub следует запускать через обёртку из корня репозитория (общепринятная практика в этом проекте — единая точка входа для PHP-CLI).

Для искусственного интеллекта и сценариев автоматизации в репозитории поддерживается структурированный навык онбординга по AXIS и отдельные регламенты по операциям, тестированию и типовым сбоям. При решении задач в коде Zen.Chub достаточно следовать описанию слоёв в этой документации и использовать консольные команды плагина там, где предусмотрена генерация или синхронизация сущностей.
