# Задачи по данным и ETL

Задачи переноса данных между системами или форматами фиксируются как отдельные рабочие потоки: источник, целевая модель, правила преобразования, обработка ошибок и уведомление ответственных.

Типичный цикл ETL для каталога включает выгрузку из внешней системы, проверку обязательных полей, сопоставление идентификаторов через алиасы, пакетную вставку или обновление в транзакции при возможности и формирование отчёта о строках с отказом.

Не полагайтесь на ручное исправление данных в продакшене без записи в журнале изменений: для повторяемости импорта правила должны быть в коде или в конфигурации, одобренной командой.
