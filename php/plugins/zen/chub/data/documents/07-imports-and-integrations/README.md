# Импорт и интеграции

Zen.Chub предусматривает **импортные пайплайны**: загрузку и преобразование данных из внешних источников в модели каталога и связанные таблицы. Такие сценарии обычно включают разбор входного формата, нормализацию кодов через алиасы, запись в основную базу и журналирование ошибок строк.

**Интеграции** с внешними системами (например, учёт клиентов или рассылки) подключаются через API плагина, очереди или запланированные задачи в зависимости от требований задержки и объёма данных.

При добавлении нового источника данных описывают контракт полей, частоту обновления, стратегию при повторном импорте (полная замена инкремента или слияние) и место хранения сырых файлов при необходимости аудита.
