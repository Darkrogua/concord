# October CMS как административная оболочка

OctoberCMS здесь выполняет роль фреймворка административной панели и маршрутизации backend-запросов. Для Zen.Chub это означает: контроллеры с поведениями списка и формы, модели ActiveRecord для таблиц с префиксом согласованным с плагином, конфигурация форм и списков в YAML, регистрация пунктов меню через конфигурацию плагина и динамический реестр сущностей.

Разработчик взаимодействует с типовыми примами October: создание и изменение записей в списках, валидация на модели, события жизненного цикла модели. Специфика домена круизов и системных процессов не «зашита» в сам October — она реализована в коде Zen.Chub (модели, сервисные классы, команды, API).

При добавлении нового экрана в админке обычно создаётся контроллер плагина, конфигурация формы и списка, при необходимости модель и миграция. Связь с общей навигацией обеспечивается через конфигурацию сущностей или явную регистрацию в меню плагина.
